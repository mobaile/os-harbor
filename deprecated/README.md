# 已废弃的实验实现

**此目录中的代码已经废弃，仅用于保存探索过程和源码参考，不继续扩展功能。它既不实现第一版完整 RAW 构想，也不实现当前第二版分区构想，不是可用的系统安装或启动产品。**

这些文件来自早期 Ventoy 实验。归档只迁移目录，不修改源码、脚本、测试或包配置的功能内容；保留的 `0.1.0` 是旧实验包版本，与 `concept-v1`、`concept-v2` 两个方案标签无关。
