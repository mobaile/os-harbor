## 后续验收场景

以下仅为研究验收要求，不是已执行步骤或安装教程。

1. **存储映射：** 固定承载分区身份、边界与扇区单位，核对目标容量，验证内部主备 GPT、文件系统及边界处读写。无效范围或标识不一致必须停止写入。
2. **透明隔离：** 同时检查安装器、正常系统和管理工具的设备视图，验证原始整盘、其他分区及控制器访问路径；单纯隐藏列表或只测试普通用户不足以通过。
3. **安装与引导保护：** 固定原版安装介质，完整完成安装；比较非目标分区、外层 GPT、Windows EFI 文件和固件变量，证明它们按要求得到保护。
4. **启动与更新：** 通过外部适配加载目标内核，从同一承载分区运行；更新内核、重建或移除可重建缓存后复验，不以维护内核或另一份系统替代。
5. **持久化与关机：** 检查写入、同步、关机和连续冷启动，记录加密及映射的释放；性能与数据一致性分别取得证据。
6. **管理与恢复：** 验证默认 Windows、一次性启动、目标缺失、内层引导失败、标识冲突和备份恢复。目标系统卡死不能推定可由 `BootNext` 自动恢复。

每份实验记录应包含日期、ISO 来源及 SHA-256、安装器与依赖版本、目标内核、硬件、承载分区身份和边界、映射方式、实际改动、检查结果及证据路径。未知项目写明未测试；若改变核心约束才成功，应明确登记差异。
