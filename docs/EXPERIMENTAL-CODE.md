# 早期实验代码说明

> **历史实验，未经端到端验证。代码不实现 [RAW 构想](CONCEPT.md)，不是可用的系统安装或启动产品。目前没有继续开发计划。**

| 位置 | 历史用途 |
|---|---|
| `osharbor/` | Windows 上登记旧路线镜像、调用 VentoyVlnk、部署配置并检查一致性。 |
| `scripts/` | 主机和镜像检查，以及在 Linux 内调用 vtoyboot 的包装脚本。 |
| `tests/` | 临时目录与替身工具上的代码行为测试，不是真实启动验证。 |
| `osharbor.ps1`、`pyproject.toml` | 旧实验的入口与包元数据；其中版本号不代表正式发行。 |

代码具有真实写入能力，例如部署 U 盘配置；“实验代码”不意味着运行没有副作用。历史命令文档仅为源码阅读参考，不应直接用于重要设备。

保留这些文件是为了记录探索过程，不继续扩展功能。关于已做和未做的测试，请阅读 [历史验证记录](VALIDATION.md)。
